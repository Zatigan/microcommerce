# Microcommerce

## Présentation
Projet de formation qui vise à intégrer les notions de microservices en s'appuyant sur ce que propose Spring pour réaliser des architectures de ce type.
Le présent projet est organisé de la façon suivante : 
- 3 microservices : order, product et inventory
- 1 gateway : portail pour consommer les microservices depuis Bruno
- un parent global pour "optimiser" les dépendances et les commandes CLI
